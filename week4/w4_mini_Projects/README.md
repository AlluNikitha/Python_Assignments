# Week 4 – Mini Project

## Assignments

1. **Contact Book App using Dictionary**
   Add, view, search, and delete contacts.

2. **Simple Calculator using Functions**
   Add, subtract, multiply, divide — with basic input validation.

3. **Automate Email Sending with `smtplib`**
   Sends an email via Gmail SMTP.
   **Setup required:** create a Gmail "App Password" at
   https://myaccount.google.com/apppasswords (needs 2-Step Verification
   enabled first). The script prompts for your email and app password
   at runtime — never hardcode a real password in the file.

4. **Weather App using OpenWeather API**
   Fetches current weather for a city.
   **Setup required:** free API key from https://openweathermap.org/api.
   Paste it into `API_KEY` in the script, or enter it when prompted.
   Note: a newly created key can take up to a couple of hours to activate.

5. **Live Cryptocurrency Price Fetcher**
   Fetches live prices using the free CoinGecko API — no API key needed.
   Requires the `requests` library (`pip install requests`).

## Requirements

Install once before running scripts 4 and 5:
```
pip install requests
```
